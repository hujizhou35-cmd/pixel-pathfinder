像素探路者 V9 · 一键运行说明

1. 双击本目录顶层的 PixelPathfinder.exe 即可运行。
2. 支持 Windows 10/11 x64。
3. 存档位置：
   %APPDATA%\Godot\app_userdata\Pixel Pathfinder\
4. 该 EXE 未使用商业代码签名。若 Windows 显示“未知发布者”或 SmartScreen：
   - 先确认文件 SHA-256 与 Build_And_EXE_Validation.md 一致；
   - 点击“更多信息”查看详情；
   - 确认来源为本次交付后再选择“仍要运行”。
5. 不需要安装 Godot。
6. 不需要旁置 .pck 文件。
7. 玩家不需要运行 BAT 或 PowerShell 脚本。

如需自行重建，可在完整项目目录中运行 build_windows.bat；这不是玩家启动游戏的必要步骤。
