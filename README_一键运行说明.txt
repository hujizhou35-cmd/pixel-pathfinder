《像素探路者》v2.0.0 Windows x64 一键运行说明

1. 推荐从 GitHub Release 下载：
   PixelPathfinder_v2.0.0_Windows_x64.zip
2. 对照 SHA256SUMS.txt 校验 SHA-256。
3. 解压 ZIP。
4. 双击 PixelPathfinder_v2.0.0_Windows_x64.exe。

系统要求：Windows 10/11 x64。
无需安装；游戏数据已嵌入 EXE，不需要独立 PCK。
程序未做商业代码签名，Windows SmartScreen 可能显示提示。

源码、MIT 许可证、第三方声明与完整验证记录：
https://github.com/hujizhou35-cmd/pixel-pathfinder

版本说明：
- GitHub 对外发行：v2.0.0
- Windows FileVersion / ProductVersion：2.0.0.0
- 游戏内既有内容标识：v5.0 · 远征路线版（按要求保持不变）
