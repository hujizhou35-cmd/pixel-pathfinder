## 逐版演进

### v1.0.0：可完整游玩的基线

这一版建立了五区节点远征、回合战斗、装备成长和区域首领，并补齐商店、背包、宝箱、事件、奖励、胜负与帮助界面。画面已经包含五张区域背景、英雄和敌人动画、天气粒子及中文像素字体。原归档没有 Windows EXE，因此公开 Release 保持为源码版。

### v1.1.0：存档、图鉴与界面栈

版本重点从“能走完整流程”转向“长时间游玩不会丢状态”。三个存档位、自动保存和旧存档迁移在此加入；奖励、商店、事件上方可以继续打开背包或图鉴，关闭后回到原界面。装备故事、严格稀有度、强化返还、事件池和分层掉落同时完善。

### v1.2.0：构筑系统成形

装备扩展为 100 件，加入元素克制、套装、21 种词条、怪物词条和武器职业差异。防御、药水与高伤害武器获得冷却；地图允许自由选关和战前侦察；熔炼、词条精华、锻打与无限强化周目共同形成长期构筑循环。

### v1.3.0：六部位、路线移动和行动顺序

头盔、裤子、鞋加入后，装备库扩展到 175 件。地图从自由点选改为可移动、可折返的路线；新档提供命名与天赋分配。战斗开始区分普攻、盾击、防御的先后手，怪物也会先攻、举盾或盾击，剑、斧、弓由此获得更明确的战术角色。

### v1.4.0：剧情 CG 与机制说明

首批剧情 CG、字幕和逐步推进交互接入开场与区域流程。节点会显示经历状态，图鉴加入机制总览；护盾和连击被收紧，熔炼获得的相同词条可以继续强化。

### v1.5.0：状态稳定与平衡修正

这一版没有扩充资源规模，而是集中修复 CG、战斗状态、音效和弹窗返回。元素、护盾与战斗结束结算的触发次数被重新梳理，冒烟测试也覆盖到新流程。

### v1.6.0：搜索、精铸与旧装备保值

图鉴加入搜索和定位，地图在换区后保存已完成节点。装备可以分解为精粹，史诗和传说装备通过精铸追赶当前区域基准。弓连击受到部位和次数限制，剑、斧增加各自的防守转进攻方案；新 CG 衔接远征开场。

### v1.7.0：周目终局首领

八岐大蛇、九尾狐、巨大三头石像和终末虚空兽成为每周目末尾的最终挑战，并拥有独立 CG。背包重新组织角色、装备与物品区域；精铸改为一次提升一级区域基准，熔炼可指定词条，怪物护盾加入生命比例上限。

### v1.8.0：旧美术体系的最终整理

在进入 V10 静态装备资源重制前，这一版集中整理程序化像素绘制、装备详情、敌人/图标画廊和弹窗边界情况，是旧美术体系最后一个完整归档。

### v2.0.0：静态装备像素资源与界面修复

V10 用固定的 20×20 图标和 40×208 四帧装备层替换运行时程序化装备绘制，加入头盔遮罩、远程武器手臂和五元素粒子层。发行前又修复了 1280×720 标题页按钮裁切与帮助窗口溢出，并增加可复现的测试、Windows 单 EXE 构建和发布校验。

## 差异核验方法

版本说明来自四类证据：相邻归档的文件清单与 SHA-256、GDScript/场景文本差异、新增或替换的图像资源，以及当时的 `upgrade*.md` 需求记录。归档内后期未更新的旧 README 只用于辅助，不作为唯一依据。
